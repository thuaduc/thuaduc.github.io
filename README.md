# thuaduc.github.io

Personal resume website of Thua-Duc Nguyen, built with Vite, React, TypeScript, Tailwind CSS, and shadcn/ui.

## Development

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
```

## Deployment

Pushes to `main` are built and deployed to GitHub Pages automatically via GitHub Actions (`.github/workflows/deploy.yml`).
